# 研究任务离线开发样例

此目录是 Agent 开发起点，不是已完成的评测集或真实文献推荐。

当前版本的真实模型手工验收入口见 [MANUAL_TESTS.md](MANUAL_TESTS.md)，
对应 [manual_cases.json](manual_cases.json) 有五题：中文/英文单事实、多证据、证据不足及近期联网发现。
前四题复用本机真实 RAGTruth v2 缓存并附已核对的原文，标准答案不传给模型；
第五题不预设在线结果。所有新用例仍待真实运行和人工验收。

- `tasks.jsonl`：六条任务草案，覆盖正常研究、查询调整、全文不可用、证据不足、
  版本/日期与预算停止。`task` 可由 `ResearchTask.from_dict` 校验。
- `synthetic_candidates.json`：明确虚构的轻量候选，不是 arXiv API 响应快照。
  `synthetic:` ID 不得用于下载。时间是测试条件，`fetched_at=null` 表示从未在线获取。
- 所有样例标记 `pending_human_review`，参考事实与页级证据尚为空；全文测试材料与
  场景对应的检索/筛选标签仍需补齐。独立适配器的真实响应快照已放在
  `tests/fixtures/arxiv/`，与此目录的虚构候选分开。`available_when_added` 只是未来模拟
  场景意图，不代表目前已有全文，也不证明 Agent 已能执行这些场景。

任务使用带 UTC 偏移的 ISO 8601 时间戳，区间为左闭右开 `[start_at, end_at)`；
输入偏移保留，检索边界统一转成 UTC，以首次提交日期判断新论文。
相对时间和 IANA 时区的界面转换后续实现。搜索会话已实现轮数与累计候选额度；
获取会话已限制下载尝试及成功论文名额，统一工具层限制总调用和本地检索次数。
执行器已加入时长检查、模型账本与显式恢复；真实 OpenAI 适配代码已接入。
历史运行记录保留在本地；修复后的真实模型决策与回答质量仍需按人工验收步骤核对。
目前可单独搜索元数据、获取固定版本 PDF、在隔离任务目录解析并索引全文，
已有模拟与真实模型决策入口。工具执行回归通过不代表这些场景已由真实模型决策完成。

原本本地测试论文及故事已退役；自动回归使用生成的 PDF 和固定来源快照。Agent 按任务获取并索引全文，不要求旧论文存在。
未完成人工复核和来源证据补齐前，不汇总质量分数、不报告提升幅度。

`tool_calls_example.jsonl` 是工具协议的显式七步集成示例，使用固定 2023 年时间窗口、
真实缓存中的 RAGTruth `2401.00396v2`，不使用虚构候选，也不表示最新论文发现。
按 README 的 `scripts/dev/run_tool_calls.py` 命令执行；`--offline` 需要本机已有对应元数据、
PDF 和模型缓存。末步只验证无引用的证据不足结果格式，不输出论文研究结论。
该文件没有模型选择或观察驱动的分支，不作为 Agent 决策或质量评测样本。

`scripts/dev/run_mock_research.py` 用固定历史候选验证 runner 的状态、预算、引用和跨进程恢复。
正常流程、查询调整、下载失败替代、重复/无进展停止、额度耗尽与中断场景由离线测试覆盖。
这些测试使用显式模拟策略，不补充本目录缺失的人工筛选标签，也不产生 Agent 质量分数。

`scripts/run_research.py` 为真实 OpenAI 入口，需要根目录 `.env` 中的 API Key（已有环境变量优先），单任务默认
0.10 美元预算、0.02 美元报告预留。`--offline-sources` 只限制文献来源，LLM 仍会联网计费。
阶段 7 的 SDK 注入测试明确标记 `injected_openai_sdk_transport_not_real_model`，即使使用真实
PDF/E5 缓存，也不是实际模型选择、回答质量或实际账单证据。正式模型轨迹应另行保留并核对。
