# 文献研究 Agent

根据主题和日期范围发现 arXiv 论文，选择并获取固定版本 PDF，将全文写入当前任务的知识库，再检索、读页和核验引文，生成带证据的短回答。

项目已收敛为 Agent 原型。原本独立的本地资料问答、旧论文默认索引及其专用评测已退役；无需准备 `paper/` 目录。PDF 解析、分块、中英文检索和引用校验仍作为 Agent 工具保留。正式研究报告尚未实现，真实模型的研究质量仍需人工验收。

## 本地运行

需要 Python 3.11+ 和 uv。在项目根目录执行：

```powershell
uv sync --locked
```

没有 uv 时，可使用系统 Python 安装 `python -m pip install uv`；已有 uv 的虚拟环境不必额外安装 pip。也可将以下命令中的 `uv` 换成 `python -m uv`。

在项目根目录 `.env` 文件中填写 API Key（已提供空文件，也可复制 `.env.example`）：

```dotenv
OPENAI_API_KEY=你的实际密钥
```

保存后启动：

```powershell
uv run python -m paper_assistant web
```

网页和命令行共用根目录 `.env` 配置，从其他工作目录启动也能读取。`.env` 已被 Git 忽略，只有空的 `.env.example` 随代码提交。保存密钥后刷新页面即可重新检查配置。

已有的 `OPENAI_API_KEY` 环境变量优先于 `.env`。如果之前在 PowerShell 配置过，先执行 `Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue`，让当前终端改用 `.env`。配置格式为单行 `KEY=value`，可加引号及行末注释，不执行变量替换。不要将真实密钥写入示例文件。

打开 **http://127.0.0.1:8501**，填写主题、首次提交日期范围和问题，点击开始研究。日期范围使用 UTC，起日包含、截止日不包含。建议首次选择 1 篇。前端不提供 token 或费用预算控件，研究额度由后台默认配置。

首次入库需要下载 `intfloat/multilingual-e5-small`；本机已缓存模型时可以运行：

```powershell
uv run python -m paper_assistant web --local-models-only
```

`--local-models-only` 只限制 embedding 模型加载；联网发现仍访问 arXiv，研究决策仍调用 OpenAI 并计费。只打开页面、查看状态不会调用模型。服务绑定本机地址，同一时间只执行一个任务。

命令行也可发起任务：

```powershell
uv run python -m paper_assistant research --task-id research-demo-01 --topic "RAG hallucination detection" --start 2026-09-01T00:00:00+00:00 --end 2026-10-25T00:00:00+00:00 --question "说明一篇相关论文的问题和主要方法，并引用正文证据" --target-papers 1 --max-cost-usd 0.10
```

新运行使用新的任务 ID。`--resume` 显式恢复兼容的检查点；变更处理代码或协议后不应续跑旧任务。`--offline-sources` 只允许使用本地文献缓存，**LLM 仍然联网计费**。失败任务不会自动重试。

## 工作流程与架构

```text
研究任务 → 模型选择动作 → 搜索候选 → 选择固定版本 → 获取 PDF
        → 解析和任务内入库 → 检索 / 读页 → 引文校验 → 短证据回答
```

这是参考 pi 分层思想、自行实现的 Python 单 Agent harness。通用核心管理消息、工具注册、执行循环和事件；研究宿主管理预算、完成条件、检查点和恢复。使用 GPT-5.4-mini，通过受控的 `research_action` 选择七个研究工具或结束任务。核心执行流程见 [research/agent.py](src/paper_assistant/research/agent.py)。

每个研究任务只检索自己的全文索引，不会读取旧论文或其他任务的索引。保留 Dense、BM25、Hybrid 检索；默认 embedding 支持中英文，实际跨语言效果仍需具体语料验证。PDF 下载成功之后仍必须成功入库才能检索。

模型上下文优先保留可引用的正文，空间不足时先缩减候选摘要、选择理由和重复历史。PDF 首页会尽量跳过标题与作者，展示实际取得的 Abstract；提问涉及方法时也会保留块内的方法段落。投影使用连续原文及对应页内偏移，完整证据保留在任务记录中。首次检索后若尚未读页或改写查询就判断证据不足，且预算允许，会提示一次补查；补查后仍可如实结束，不保证一定得到充分证据。

文献搜索的工具反馈明确列出候选数量与 ID，并提示筛选、下载和入库。模型重复已成功且返回候选的相同搜索时，程序拦截请求并给一次纠正机会，不消耗额外搜索轮次；默认再次重复则停止。仍可改写关键词、改变排序或请求更多候选，所有模型决策仍受原预算和时限约束。

## 围绕当前论文继续讨论

研究停止且至少一篇论文成功入库后，回答下方的“继续讨论”可输入追问，例如“刚才的方法有哪些局限？”或“这些实验是否支持这个结论？”。每轮复用该任务的论文，结合前文理解指代，重新检索或读页，再校验回答与引文。历史回答不会直接当作正文证据；第一版不自动发现、下载或添加新论文。

“列出刚刚参考的论文”等文献列表问题使用 `list_references`：默认按上一条核验回答的引用记录返回题名、作者、固定版本 arXiv 编号及链接，也可列出本对话引用过的论文或全部已入库论文。这类回答核对已保存的引用关系和登记元数据，使用独立的“论文元数据已核对”标记；方法、实验和结论等正文回答仍须检索、读页并校验原文引文。搜索到但未引用的候选不能冒充“刚刚参考”的论文。

网页研究任务使用后台默认 **$0.10** 额度，追问单轮默认 **$0.05**；每个研究任务的追问累计预算上限 **$0.50**、最多 **20 轮**，独立于初始研究预算。页面只读展示累计用量及估算费用，不提供预算设置。执行中或结果未确认的轮次保守预留整轮预算；估算仍不等于账户硬限额。

对话保存在任务下的 `conversation.json` 和 `conversation/<turn-id>/`，每轮保留问题、历史上下文、模型用量、工具日志和检查点。刷新后会恢复显示；重新连接只读状态，重复提交同一请求标识不会再次执行。服务重启时未确认的轮次标为中断，不自动重试；可显式提出下一轮问题。停止按钮在当前步骤完成后停止后续调用。

“继续讨论”顶部可**新建对话**、通过下拉框**切换已有对话**，或**重置当前对话**。新建会创建独立的追问上下文，旧对话仍可切回；重置会清空当前追问内容和上下文，旧轮次保留在本地审计记录中。原研究结果继续作为背景，已入库论文无需重新获取。新建、切换、重置均不调用模型；执行中的追问须先停止并等待结束。

所有对话共享该研究任务的 **20 轮和 $0.50 追问上限**，新建或重置不会清零累计费用、轮数或未知调用的预算预留。旧版本记录在读取时作为“对话 1”展示；只有显式操作才会保存新对话元数据。

首次使用请重启页面服务并刷新页面。追问以只读方式复用既有索引，允许解析代码路径或指纹变化；仍检查任务绑定、索引格式、PDF 哈希及 embedding 身份，不重新入库或改写原任务。继续写入旧工作区仍要求原处理指纹一致。预检失败会显示具体原因，确认未请求模型的失败轮次不占用追问预算。真实模型对话质量仍需按 [追问验收步骤](eval_data/research/CONVERSATION_TESTS.md) 人工核对。

引用检查验证证据 ID、页码来源和逐字引文匹配；它不等于验证回答的全部推理或语义正确性。预算是根据 token 用量和记录费率估算，包含报告预留；正式报告尚未使用该预留。未知请求结果按预留保守记账并停止。

## 目录与数据

```text
src/paper_assistant/
  ai/             # 模型契约与 OpenAI 客户端
  agent/          # 通用内核：消息、工具注册与执行循环
  research/       # 研究应用：任务、预算、模型适配、工具审计与知识库
  tools/          # arxiv/ 文献能力；knowledge/ PDF 与三种检索
  web/            # 本地研究页面及任务 API
  __main__.py     # 统一启动入口
  config.py       # .env 配置
  storage.py      # 原子写入
scripts/          # 两个兼容入口；dev/ 存放能力调试和模拟脚本
tests/            # 按 ai、agent、research、tools、web 分组
eval_data/research/# Agent 开发场景与人工验收用例
```

本地运行会生成 `data/models/`、`data/literature_search/`、`data/paper_cache/` 和 `data/research_runs/`。任务目录保存全文索引、来源、工具日志、预算、消息和检查点。这些数据、PDF、密钥及本地笔记不上传 GitHub。

旧论文、默认索引、旧版脚本及专用评测资料已移至本机忽略目录 `tmp/legacy-rag-20261025/`。它们不参与运行。Agent 的缓存和研究记录保留；RAGTruth 固定历史示例属于 Agent 测试材料，可按需使用，与旧 `paper/` 语料无关。
